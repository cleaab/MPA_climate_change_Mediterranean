# MPA_climate_change_Mediterranean

This repository contains data and code used to obtain results of the paper Abello et al. (202?) - Assessing the potential of marine protected areas to mitigate climate change impacts in the Mediterranean Sea submitted to Global Change Biology.

Model code and configuration used for running the scenarios are accessible on zenodo: [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.18545815.svg)](https://doi.org/10.5281/zenodo.18545815)

Raw model outputs used for the analyis exceeded 50 Terabytes and could not be uploaded on Zenodo, but are available upon request. Main contact: Clea Abello clea.abello@gmail.com. Aggregated outputs used for the analysis and the scripts to generate them are available in the data folder on Zenodo: [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.18545815.svg)](https://doi.org/10.5281/zenodo.18545815)

To run the analyses:
 - Clone the git directory
 - Open the .Rproj file in RStudioRun and run the main file Main.Rmd.
If you are not able to download data directory automatically from Main.Rmd, download it manually from the zenodo repository DOI and place it at the root of the repository.
 - Run the scripts in the code/figures_manuscript to make the figures

For info on the MPA scenarios: see [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.16734084.svg)](https://doi.org/10.5281/zenodo.16734084)
